## Lab 1: Multilayer Perceptron (MLP)
In this lab, we implemented a simple Multilayer Perceptron (MLP) from scratch and later using PyTorch.

### Objectives:
- Build an MLP from scratch using Python and NumPy.
- Implement the same MLP using PyTorch for a more efficient and scalable approach.

### Files:
- `MLP_in_python.ipynb`: MLP implemented from scratch using Python.
- `MLP_in_pytorch.ipynb`: MLP implementation using PyTorch.

---

## Lab 2: Recurrent Neural Networks (RNNs) and Transformers
In this lab, we explored sequence modeling through Recurrent Neural Networks (RNNs) and Transformer models to build language models.

### Objectives:
- Understand and implement RNN-based models.
- Explore Transformer architectures and apply them to language modeling tasks.

### Files:
- `RNN_movie_rating_prediction.ipynb`: Implementation of an RNN for movie rating prediction.
- `RNN_LLM_MidiGen.py`: Transformer-based language model to generate music.

---

## Lab 3: Convolutional Neural Networks (CNNs)
In this lab, we shifted focus to image data, implementing Convolutional Neural Networks (CNNs) for image classification tasks.

### Objectives:
- Understand the architecture of CNNs and their application to image classification.
- Implement a CNN from scratch using PyTorch.

### Files:
- `cnn_model.py`: CNN implementation for image classification.
